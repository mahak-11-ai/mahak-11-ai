## ⭐ Featured Projects

### Event Management System

> A full-stack platform for running events, from participants to volunteers, in one place.

#### Overview

Organizing an event involves many moving parts: defining the event, keeping track of who is taking part, recruiting volunteers, and making sure every responsibility has an owner. The Event Management System brings that workflow into a single application instead of leaving it to scattered messages and manual coordination.

It is a full-stack web application built around the practical needs of event organizers and the people who help them.

#### Key Features

- Event creation
- Participant management
- Volunteer recruitment
- Assigning responsibilities to volunteers
- Management of event activities
- Token-based authentication with protected routes

#### Technical Implementation

The frontend is built with **React** and **Vite**. The backend is a **Node.js** and **Express.js** API backed by **MongoDB**. **Cloudinary** is integrated for media handling. Access is controlled with **token-based authentication**, and **protected routes** keep parts of the application limited to signed-in users.

#### What I Learned

This project taught me how the layers of a full-stack application connect: a React frontend talking to an Express API, data stored in MongoDB, and authentication running across both sides so that tokens are issued, sent with requests and used to protect routes.

### Predictive Text Generator

> A Python program that predicts the next word and generates short sentences with a bigram model.

#### Overview

This is a small NLP and machine-learning project that shows how n-gram models can drive text prediction. The program learns from a plain text file, and when you type a word it suggests the words most likely to come next. It can also extend that into a short generated sentence. The repository describes it as a simple NLP project, and it began as an internship submission.

#### Key Features

- Next-word prediction from a typed word
- Short sentence generation
- Learns from a training text file (`data.txt`)
- Saves interactions to a history file (`history.txt`)
- Interactive command-line usage

#### Technical Implementation

Written in **Python** and built around a **bigram model**, which uses word pairs found in the training data to decide which word tends to follow another. The training data and the interaction history are both plain text files.

#### What I Learned

This project showed me how a language model can be built from simple word-pair statistics, and why richer approaches exist. The repository lists trigram models, neural networks, a GUI and user-supplied datasets as natural next steps.

#### Links

[Repository](https://github.com/mahak-11-ai/predictive-text-generator)
